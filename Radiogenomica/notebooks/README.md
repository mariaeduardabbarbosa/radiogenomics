# Notebooks Directory

Este diretório contém Jupyter notebooks e scripts Python para análise e processamento dos dados radiogenômicos.

## Conteúdo

- Notebooks de análise exploratória
- Scripts de pré-processamento de dados
- Notebooks de treinamento de modelos
- Scripts de análise de resultados

## Organização Sugerida

```
notebooks/
├── 01_preprocessing/       ← Notebooks de pré-processamento
├── 02_exploratory/        ← Análise exploratória de dados
├── 03_modeling/           ← Desenvolvimento de modelos
└── 04_evaluation/         ← Avaliação e análise de resultados
```
