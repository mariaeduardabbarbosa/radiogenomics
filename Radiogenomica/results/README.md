# Results Directory

Este diretório armazena tabelas, gráficos e outros outputs gerados durante a análise.

## Conteúdo

- Tabelas de resultados (CSV, Excel)
- Gráficos e visualizações (PNG, SVG)
- Métricas de desempenho dos modelos
- Arquivos de output intermediários

## Organização Sugerida

```
results/
├── tables/        ← Tabelas de resultados
├── plots/         ← Gráficos e visualizações
└── metrics/       ← Métricas de desempenho
```
