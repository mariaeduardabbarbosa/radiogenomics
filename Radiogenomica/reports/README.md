# Reports Directory

Este diretório contém figuras e relatórios em PDF dos resultados da pesquisa.

## Conteúdo

- Figuras de alta qualidade para publicações
- Relatórios em PDF
- Apresentações
- Documentação de resultados

## Organização Sugerida

```
reports/
├── figures/         ← Figuras para artigos e apresentações
├── pdfs/           ← Relatórios em PDF
└── presentations/  ← Slides e apresentações
```

**Nota**: Use formatos vetoriais (SVG, PDF) para figuras de publicação quando possível.
